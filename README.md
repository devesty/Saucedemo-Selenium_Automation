# SauceDemo Selenium Automation Project

## Project Overview

This project automates the end-to-end shopping
workflow on the SauceDemo web application.

It covers login, product selection, cart management,
and checkout verification.

## Technologies Used

- Java 17
- Selenium WebDriver
- TestNG
- Maven
- Eclipse IDE
- Chrome Browser

## Test Scenarios

1. Login with valid credentials.
2. Add multiple products to cart.
3. Verify cart item count.
4. Remove selected products.
5. Verify updated cart count.
6. Complete checkout.
7. Verify successful order confirmation.

## Automation Features

- Selenium WebDriver browser automation
- TestNG annotations
- Explicit waits
- Assertions
- Looping through multiple products
- Browser setup and teardown

## How to Run

1. Clone this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Allow Maven to download dependencies.
4. Run the test class using TestNG.
